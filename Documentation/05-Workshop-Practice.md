Praktik Akhir: Membuat Student Task Planner dengan AI dan GitHub.

Catatan dan Rangkuman Materi
Sesi praktik menggabungkan semua materi yang telah dipelajari dengan tujuan membuat sebuah aplikasi sederhana bernama Student Task Planner

Buka / Install platform asisten AI (seperti Claude, ChatGPT, dll).
Tulis instruksi (prompt) dengan format Role-Task-Context-Format yang baik untuk men-generate kode aplikasi web
Simpan file hasil kode, lalu jalankan git init di folder tersebut
Lakukan commit pada kode awal dan di-push ke repository GitHub.
Lakukan perubahan pada kode jika diperlukan
Lakukan commit dan push kembali ke GitHub untuk menyimpan versi terbarunya
