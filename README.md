DOKUMENTASI WORKSHOP: BUILDING WITH AI, MANAGING CHANGE WITH GITHUB

Dandy Aulia


Repository ini dibuat sebagai bentuk penugasan Day-1 workshop Building with AI, Managing Change with GitHub. Repository ini menyimpan rangkuman materi, catatan pembelajaran, dan dokumentasi praktik yang diajarkan selama sesi berlangsung

Tujuan utama repository ini adalah untuk memenuhi syarat pengumpulan tugas, mempraktikkan penggunaan dasar Git dan GitHub secara langsung, serta menjadi catatan referensi pribadi mengenai teknik Prompt Engineering dan Version Control System di masa mendatang


Workshop ini diisi oleh Nugi Farhan, Senior Product Designer. Topik utamanya menjembatani cara merancang instruksi (prompt) AI yang efektif agar menghasilkan output spesifik, dipadukan dengan cara melacak dan mengelola perubahan kode pengembangan menggunakan Git dan GitHub secara terstruktur. Praktik akhir dari workshop ini adalah membangun sebuah web sederhana bernama Student Task Planner.
